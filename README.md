# Компьютерное зрение — лабораторные работы (Jupyter)

Репозиторий подготовлен под серию лабораторных по компьютерному зрению в формате ноутбуков с пояснениями.

## Структура

- `notebooks/lab1_nonlinear_regression.ipynb` — Лабораторная №1 (нелинейная регрессия, BatchNorm/Dropout)
- `notebooks/lab2_dvm_car_color_classification.ipynb` — Лабораторная №2 (классификация цвета авто, DVM)
- `requirements.txt` — зависимости Python
- `data/` — данные (сырые и подготовленные)
- `models/` — веса/чекпойнты (по желанию)
- `reports/` — графики и отчеты (по желанию)

## Быстрый старт

1. Создать и активировать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить Jupyter:

```bash
jupyter notebook
```

4. Открыть ноутбук из папки `notebooks/`.

## Лабораторная 1

Ноутбук: `notebooks/lab1_nonlinear_regression.ipynb`

Что реализовано:
- генерация 3 разных нелинейных функций с шумом;
- фиксированная MLP-конфигурация:
  - слои: `1 -> 128 -> 64 -> 1`,
  - активация: `ReLU`,
  - loss: `MSELoss`,
  - optimizer: `Adam`,
  - `lr=1e-3`,
  - `epochs=250`;
- часть 1: сравнение 3 размеров батча (`16`, `32`, `64`) только с BatchNorm;
- часть 2: 4 режима регуляризации на лучшем batch size:
  1) без BN и dropout,
  2) только BN,
  3) только dropout,
  4) BN + dropout;
- визуализации:
  - сравнение метрик,
  - графики исходной функции, шумных точек и лучшей аппроксимации.

## Лабораторная 2

Ноутбук: `notebooks/lab2_dvm_car_color_classification.ipynb`

Задача: классификация цвета автомобиля по фронтальным изображениям из DVM.

### Подготовка данных

1. Скачать набор **Quality checked front-view images (730 MB)** с сайта DVM:
   - https://deepvisualmarketing.github.io/
2. Распаковать в:

```text
data/raw/dvm_front/
```

Ожидаемая структура:

```text
data/raw/dvm_front/Brand/Model/Year/Color/*.jpg
```

### Что реализовано в ноутбуке

- построение индекса изображений и меток цвета из структуры папок;
- нормализация названий цветов и фильтрация редких классов;
- стратифицированное разделение на train/val/test;
- **модель с нуля**: ручная реализация ResNet-подобной CNN (`SmallResNet`);
- **предобученная модель**: `ResNet18 (ImageNet)` + fine-tuning;
- обучение с логированием `loss` и `F1_macro`;
- финальная оценка на test и сравнение моделей;
- classification report + confusion matrix.

Целевая метрика по условию лабораторной: `F1_macro > 0.8`.
